# Anthropic connectors directory

Name: LSports ARENA360

Remote URL: `https://arena-mcp.lsports.eu/arena/mcp`

Sign-in uses the operator's ARENA360 credentials.

Description: the shared string in `docs/listing-copy.md`

Access is read and write for modules that expose tools. Writes are shown and approved before they are applied. DEFEND and ENGAGE have no hosted tools.

Audience is B2B sportsbook operators. The connector does not place bets.
